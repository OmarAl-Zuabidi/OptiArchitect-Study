# Code of conduct

This project is a teaching tool used by students and instructors. We expect everyone taking part
(issues, pull requests, discussions) to be respectful, constructive and welcoming regardless of
background, language or experience level.

Not acceptable: harassment, personal attacks, discriminatory language, or publishing others' private
information. Maintainers may edit or remove contributions that do not follow this code and may block
repeat offenders. Report concerns through GitHub's private reporting on this repository.

This statement is adapted in spirit from the Contributor Covenant (https://www.contributor-covenant.org).
